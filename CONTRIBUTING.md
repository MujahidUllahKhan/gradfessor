# Contributing

Thanks for helping. Gradfessor is maintained by Mujahid Ullah Khan Afridi.

## How to contribute

1. Open an issue first for anything bigger than a small fix, so we agree on the idea.
2. Fork the repository, create a branch (`git checkout -b fix-deadline-colors`).
3. Keep it simple: plain HTML/CSS/JS, no build step, no new libraries without discussion.
4. Run `npm test` (and the browser tests if you changed the UI or the extension).
5. Commit with a sign-off: `git commit -s -m "Fix deadline colours"`.
6. Open a pull request. Every pull request needs the maintainer's review before it is merged.

## Sign-off (Developer Certificate of Origin)

`-s` adds a `Signed-off-by:` line. It means you wrote the change (or have the right to submit it) and agree it is published under this project's license, as described at https://developercertificate.org.

## Ground rules

- Use fictional data in code, tests and screenshots. Never real students' CVs or emails.
- No scraping of Google Scholar, LinkedIn or email inboxes. The project only reads pages the student opens or public faculty pages, politely.
- Be kind. See CODE_OF_CONDUCT.md.
